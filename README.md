<h1 align="center">Today</h1>

<p align="center">
  Минималистичный список дел в строке меню macOS и трее Windows.<br>
  Быстро открывается, не требует аккаунта и хранит данные только на вашем компьютере.
</p>

## Возможности

- открытие списка при наведении на значок в строке меню;
- закрепление окна обычным кликом;
- системное меню с завершением приложения по правому клику;
- включение и отключение автозапуска из меню по правому клику;
- добавление, редактирование, выполнение и удаление дел без отдельного окна;
- поиск по тексту задач в текущем списке и истории, без учёта регистра и различий «е/ё»;
- одно меню `…` у каждой задачи: приоритет, срок, раздел, копирование и удаление;
- три уровня приоритета с одним, двумя или тремя монохромными огоньками;
- круглые чекбоксы и гарантированное зачёркивание выполненных задач;
- разделы «Работа» и «Личное» с возможностью создавать свои;
- удаление пользовательских разделов без удаления находящихся в них задач;
- необязательные сроки, визуальная пометка просрочки и системные напоминания macOS;
- собственный календарь с недельной полосой и ручным вводом цифрового времени;
- быстрое добавление: `Enter` сохраняет задачу, `Shift + Enter` создаёт новый абзац;
- системные команды копирования, вставки, вырезания и выделения текста;
- полный текст задач без обрезки;
- автоматический перенос незавершённых дел на следующий день;
- сворачиваемый список выполненных дел за сегодня;
- история выполненных дел с группировкой по датам;
- общий выбранный раздел для «Сегодня», «Истории», поиска, прогресса и счётчиков;
- современная скруглённая панель в стиле macOS, ChatGPT и Notion;
- увеличенная типографика и вкладки, равномерно занимающие доступную ширину;
- светлая и тёмная темы с нейтральными фонами;
- полностью локальная работа без сервера, аналитики и регистрации.

## Совместимость

macOS-сборка является Universal Binary и предназначена для:

- Mac с Apple Silicon (`arm64`);
- Mac с процессором Intel (`x86_64`);
- macOS 13 Ventura или новее.

Windows-версия — отдельное нативное приложение C#/WPF на .NET 10, без браузерной оболочки.
Предусмотрены сборки для Windows 11 **x64** (Intel/AMD) и **ARM64** (например, Snapdragon).
Среда .NET включена в готовый `Today.exe`: отдельно устанавливать её не нужно.
Поддерживаемые редакции Windows 10 с ESU/LTSC зависят от
[системных требований .NET](https://learn.microsoft.com/dotnet/core/install/windows);
устаревшие Windows 7/8 и 32-разрядная Windows не поддерживаются этой сборкой.

## Установка

### Актуальные сборки из main

Откройте [Build в GitHub Actions](https://github.com/IwanBelenko/TodayBar/actions/workflows/build.yml),
выберите последний успешный запуск ветки `main` и скачайте нужный файл из **Artifacts**:
`Today-universal`, `Today-windows-x64` или `Today-windows-arm64`.
Для скачивания артефактов GitHub требуется вход в аккаунт; срок их хранения ограничен GitHub.
Опубликованные ранее версии доступны на странице [релизов](https://github.com/IwanBelenko/TodayBar/releases).

### macOS

1. Скачайте `Today-universal` из успешного Build либо архив нужного опубликованного релиза.
2. Распакуйте скачанный архив (артефакт GitHub может содержать ещё один ZIP).
3. Распакуйте архив и переместите `Today.app` в папку «Программы».
4. При первом запуске нажмите на приложение правой кнопкой и выберите «Открыть».

Приложение подписано локальной подписью. Поэтому macOS может запросить дополнительное подтверждение при первом запуске вне Mac App Store.

### Windows

1. Выберите `Today-windows-x64` для обычного ПК Intel/AMD или `Today-windows-arm64` для Windows on ARM.
2. Распакуйте архив в постоянную папку, например `%LOCALAPPDATA%\Programs\Today`.
3. Запустите `Today.exe`. Значок появится возле часов; Windows может спрятать его под стрелкой скрытых значков.
4. Наведите курсор для просмотра списка или нажмите левой кнопкой для работы с ним. `Esc` и клик вне окна скрывают панель.
5. Правый клик по значку → `Launch at Startup` включает/отключает запуск при входе; `Завершить Today` полностью закрывает приложение.

Это переносимое приложение, установщик и права администратора не нужны. Цифровой подписи
издателя Windows пока нет, поэтому SmartScreen может показать предупреждение. Не отключайте
защиту Windows целиком; используйте только сборки из этого репозитория, которым доверяете.
Перед обновлением завершите Today через значок и замените `Today.exe`. Данные останутся на месте.
Если переместили папку с приложением, заново включите `Launch at Startup`, чтобы обновить путь.
Чтобы удалить приложение, сначала отключите автозапуск и завершите Today, затем удалите его папку.

## Автозапуск

На обеих платформах нажмите правой кнопкой на значок Today и включите `Launch at Startup`. Повторный клик снимает галочку и отключает автозапуск. В Windows настройка действует только для текущего пользователя и не требует прав администратора.

Также настройку можно проверить вручную:

1. Откройте «Системные настройки».
2. Перейдите в «Основные → Объекты входа».
3. Нажмите `+` и выберите `Today.app` из папки «Программы».

## Управление

| Действие | Результат |
| --- | --- |
| Навести курсор на значок | Быстро показать список |
| Нажать левой кнопкой | Закрепить или закрыть окно |
| Нажать правой кнопкой | Открыть меню приложения |
| `Launch at Startup` в меню | Включить или отключить запуск при входе в macOS |
| Нажать «Сегодня» или «История» | Переключить раздел на всей ширине вкладки |
| Нажать «Работа», «Личное» или свой раздел | Отфильтровать текущие задачи, историю и счётчики; выбор сохраняется при переключении вкладок |
| Нажать `+` рядом с разделами | Создать пользовательский раздел |
| Правый клик по пользовательскому разделу | Удалить раздел, сохранив его задачи |
| Поле «Поиск задач» или `⌘F` / `Ctrl+F` | Искать по тексту в текущей вкладке и выбранном разделе |
| `Esc` в поле поиска или крестик | Сбросить поиск |
| `…` у задачи → «Приоритет» | Выбрать низкий, средний, высокий приоритет или убрать отметку |
| `…` у задачи → «Добавить / Изменить срок…» | Открыть календарь и изменить дату или время |
| `…` у задачи → «Раздел», «Скопировать задачу», «Удалить задачу» | Изменить раздел, скопировать полный текст или удалить задачу |
| Нажать на часы или минуты | Ввести цифровое время вручную |
| Нажать `−` или `+` рядом со временем | Изменить время на 15 минут |
| `⌘C` / `⌘V` / `⌘X` | Копировать, вставить или вырезать текст |
| Правый клик по выполненной задаче | Скопировать задачу целиком |
| `Enter` при вводе | Сохранить задачу |
| `Shift + Enter` | Добавить новый абзац |
| Нажать на чекбокс | Выполнить или вернуть задачу |

В Windows вместо `⌘` используются сочетания с `Ctrl`. Текст существующей задачи сохраняется по Enter или при переходе из редактора; Shift+Enter добавляет строку.

Поиск проверяет все введённые слова, включая текст на новых строках. Переключение между «Сегодня» и «История» сохраняет запрос **и выбранный раздел**. Счётчик вкладки, просрочка и прогресс учитывают раздел, но не сужаются поисковым запросом. «Все» показывает все разделы и задачи без раздела. Добавление новой задачи сбрасывает запрос.

В истории кнопка «Очистить» удаляет выполненные дела только выбранного раздела; в «Все» — всю историю. Перед удалением есть подтверждение. При поиске массовая очистка скрыта.

Приоритет обозначен нейтральными огоньками под текстом: один — низкий, два — средний, три — высокий. Задачи автоматически идут в порядке **3 → 2 → 1 → без огоньков**, включая поиск и выбранный раздел. При изменении приоритета положение обновляется сразу. При одинаковом приоритете незавершённые задачи сохраняют порядок создания, выполненные — обратный порядок завершения. Выполненные остаются в своём блоке; история сохраняет группировку по дням, сортируя по приоритету внутри каждого дня. Приоритет сохраняется вместе с задачей; у существующих и новых задач по умолчанию его нет.

## Где хранятся данные

Задачи и пользовательские разделы сохраняются локально:

```text
~/Library/Application Support/TodayBar/tasks.json
~/Library/Application Support/TodayBar/categories.json
```

В Windows используются `%APPDATA%\TodayBar\tasks.json` и `%APPDATA%\TodayBar\categories.json`.
Предыдущая сохранённая версия каждого файла остаётся рядом с расширением `.bak`.
Повреждённый файл не заменяется пустым списком: приложение сообщает об ошибке чтения.

Удаление приложения не удаляет эти файлы автоматически. Для переноса между Mac и Windows
завершите Today на обоих компьютерах, сохраните резервную копию, затем скопируйте **оба JSON-файла**
в папку TodayBar нового компьютера. Перенос заменяет его текущий список, а не объединяет списки.
Сроки хранятся как моменты времени UTC и отображаются в местном часовом поясе. Автосинхронизации нет.

### Напоминания Windows

Пока Today работает в трее, он проверяет сроки каждые 15 секунд и показывает системное
уведомление. Просроченные задачи остаются помеченными в списке; при следующем запуске
показывается напоминание о пропущенных сроках. Один срок не напоминается повторно в той же
сессии. После полного выхода из Today или при выключенном ПК Windows-версия не отправляет
уведомления — включите автозапуск, если нужны постоянные напоминания. «Не беспокоить»
и настройки Windows могут скрывать уведомления.

## Сборка из исходного кода

Для сборки нужен Mac с актуальными Xcode Command Line Tools или Xcode.

```bash
git clone https://github.com/IwanBelenko/TodayBar.git
cd TodayBar
./scripts/build-app.sh
```

Готовое приложение появится в:

```text
dist/Today.app
```

Скрипт собирает единое приложение для Intel и Apple Silicon и подписывает его локальной ad-hoc подписью.

### Windows из исходников

Для разработки установите [.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0).
В PowerShell из корня репозитория:

```powershell
dotnet run --project Windows/Today.Core.Tests
dotnet run --project Windows/Today.Windows
./scripts/build-windows.ps1 -Runtime win-x64
./scripts/build-windows.ps1 -Runtime win-arm64
```

Готовые автономные приложения: `dist/Today-win-x64/Today.exe` и `dist/Today-win-arm64/Today.exe`.
Режим `--startup` открывает приложение сразу в трее, не показывая окно.
Для кросс-сборки на Mac/Linux с .NET SDK 10:

```bash
dotnet publish Windows/Today.Windows -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:PublishTrimmed=false \
  -o dist/Today-win-x64
```

Кросс-сборка не проверяет работу окна на Windows. Приложение не требует сторонних пакетов;
Windows Desktop reference/runtime packs для сборки загружаются из NuGet.

## Проверки

Для тестов нужен Swift 6 или новее; минимальная версия системы для запуска тестов зависит от установленной библиотеки Swift Testing (в текущих Command Line Tools — macOS 14). Само приложение по-прежнему собирается для macOS 13+.

```bash
./scripts/test.sh
```

Тесты проверяют чтение старых файлов без приоритетов, сохранение новых полей, сортировку по огонькам и её обновление, поиск с фильтром разделов, порядок дней истории и обработку Enter только активным редактором. Они используют временные данные и не читают личный список задач.

Windows: `dotnet run --project Windows/Today.Core.Tests` проверяет поиск, приоритеты,
сроки и переходы суток/DST, историю по разделам, совместимость JSON, сохранение и ошибки записи.
На Windows команда `Today.exe --smoke-test <папка>` запускает отдельный режим с временными
данными: создаёт окно, проверяет фильтрацию, действия меню, добавление и копирование,
сохраняет снимки светлой/тёмной темы и календаря. Автозапуск и личные данные не затрагиваются.
GitHub Actions запускает эти проверки на Windows x64 и собирает оба варианта EXE.
Ручная проверка наведения в трее, уведомлений, автозапуска, разных DPI и ARM64 остаётся
отдельной проверкой на соответствующем устройстве — снимки интерфейса её не заменяют.

Для дополнительных снимков интерфейса на тестовых данных:

```bash
TODAYBAR_SNAPSHOT_DIR="$PWD/.build/ui-previews" ./scripts/test.sh
```

В набор входят светлая и тёмная темы, найденная задача, пустая выдача и поиск по истории. При необходимости можно указать установленный SDK через переменную `SDKROOT`.

## Архитектура

Проект разделён на независимые слои:

```text
AppSources/TodayBar
├── App             # жизненный цикл и интеграция со строкой меню
├── Data            # локальное JSON-хранилище
├── Domain          # модель задачи
└── Presentation    # SwiftUI-интерфейс и состояние экрана
```

Windows-реализация находится рядом и не заменяет нативный Swift-код:

```text
Windows
├── Today.Core          # модели, фильтры, сортировка и атомарное JSON-хранилище
├── Today.Core.Tests    # переносимые проверки на временных данных
└── Today.Windows       # WPF, трей, календарь, автозапуск и уведомления
```

Связь платформ — совместимый формат данных и одинаковое поведение, без сервера и межъязыкового моста.

## Помощники разработки

Проектные инструкции находятся в [AGENTS.md](AGENTS.md). Из HCM/LMS перенесены
навыки Ponytail, frontend-design и связка grill-me/grilling; роли исследователя кода,
разработчика и UI-проверяющего адаптированы под Swift/macOS. Вместо серверного
проверяющего прав добавлена роль проверки сохранности локальных задач.

Навыки хранятся в `.agents/skills`, роли — в `.codex/agents`. Источники и контрольные
суммы записаны в `.agents/skills/sources.json`. Это инструкции для разработки, а не
AI-функции внутри Today: новых зависимостей, сетевых запросов или фоновых агентов в
приложении нет. Они не меняют глобальную модель и не разрешают публикацию.

Открывайте сессию Codex в корне `TodayBar` для проектного обнаружения. В локальном
родительском каталоге ChatGPT-проекта используются ссылки на эти же папки; в другом
клоне они не нужны. В уже открытом чате новое обнаружение ролей не подтверждено;
правила содержат вариант явной передачи инструкции роли при делегировании.

## Конфиденциальность

Today не использует сеть и не отправляет аналитику. Данные остаются на компьютере.
В macOS разрешение на системные уведомления запрашивается при добавлении первого срока.
Windows использует системные уведомления из трея и запись автозапуска текущего пользователя
только по нажатию `Launch at Startup`. Приложение не меняет автозапуск автоматически при первом открытии.
