<h1 align="center">Today</h1>

<p align="center">
  Ваши дела — всегда под рукой.
</p>

Минималистичный список дел для Mac и Windows. Записывайте задачи, выделяйте важное
и отмечайте сделанное — в компактном окне, которое открывается одним кликом по значку приложения.

## Всё нужное для ваших дел

- **Работа и личное.** Разделяйте задачи по готовым разделам или создавайте свои.
- **Важное — наверху.** Отмечайте приоритет огоньками: чем их больше, тем выше задача.
- **Сроки под контролем.** Назначайте дату и время, получайте напоминания и замечайте просроченное.
- **Ничего не теряется.** Находите задачи поиском и возвращайтесь к сделанному в истории.

Светлая и тёмная темы. Русский и английский язык — автоматически по настройкам системы.

## Просто начать

**Mac:** распакуйте архив, перенесите Today в «Программы» и запустите.

**Windows:** распакуйте архив и откройте Today.exe.

При первом запуске система может показать предупреждение о неподтверждённом разработчике.
[Помощь с установкой и предупреждениями](docs/GUIDE.md#как-установить).

Today работает без интернета и регистрации. Данные хранятся на вашем компьютере;
синхронизации между устройствами нет.
